## 검토 항목

1. **코드 품질**
   - 가독성 및 명명 규칙
   - 중복 코드
   - 복잡도

2. **보안**
   - 입력 유효성 검사
   - SQL Injection, XSS
   - 민감 정보 노출

3. **성능**
   - 불필요한 연산
   - 메모리 누수 가능성
   - N+1 쿼리

4. **테스트**
   - 테스트 커버리지
   - 엣지 케이스
