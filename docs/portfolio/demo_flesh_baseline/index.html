Score 공식 (설명 가능)
  • compatibility (50%) = axis 매칭 (0.5) + dominant_pressures × profile.compatible_pressures overlap × 0.5
  • annotation (50%) = Σ(feature_score normalized × profile.feature_weight)
  • annotation이 없으면 compatibility-only fallback (Phase 3.0 통과 전 상태)
  • fit_label: ≥ 0.7 strong / ≥ 0.5 moderate / ≥ 0.25 weak / 그 외 no_fit
