Score 공식 (설명 가능)
  • annotation feature 각 annotator 점수 평균 → 0-5 → 0.0-1.0 normalize
  • intensity_score = Σ (normalized × profile.feature_weights[f]) — KEEP feature만
  • fit_label: ≥ 0.7 strong / ≥ 0.5 moderate / ≥ 0.25 weak / 그 외 no_fit
  • profile.feature_weights는 Phase 3.0 reliability KEEP 통과 후 정규화 (sum=1)
