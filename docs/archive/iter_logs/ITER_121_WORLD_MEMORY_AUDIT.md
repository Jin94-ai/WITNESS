- Decays at HL ~45 ticks

  RumorRegistry until intensity decays below threshold

- This is path-dependent: WHO confessed determines WHICH rumor
  is active, which determines who gets recovery

- Affects accusation event generation rate
- Couples to dominant_emotion ("anger" or "fear")
- Active memory: ambient suspicion shifts future event possibility

## 3. Combined picture

Existing world-side memory + meso-scale state:
1. **shame_climate** -- ambient shame pressure with decay
2. **public_suspicion** -- ambient suspicion with decay
3. **blame_concentration** (per role) -- targeted blame with rumor-mediated reduction
4. **alignment_strength** -- crowd cohesion variable, decays with density
5. **dominant_emotion** -- crowd phase indicator (anger/fear/awe/celebration/indifferent/mourning)
6. **density** -- crowd participation, decay
7. **forgiveness_rumors (in RumorRegistry)** -- per-role active forgiveness
8. **threat_rumors (in RumorRegistry)** -- per-role active threat

**8 layers total**, of which 4-5 are memory-like (persist past their
generating event, decay over time, affect future state).

This is **multiple memory channels working simultaneously**, which
matches the Score-3 World Memory criterion.

## 5. Why NOT add wishlisted layers (forgiveness_trace etc.)

Tempting: add forgiveness_trace, unresolved_group_tension,
local_trust_climate to "complete" the wishlist.

But Iter 105-119 lessons:
- Aux mechanisms (Iter 92-103) were investigated and found to be
  decorative phantoms -- they fired <1% of horizon
- Real recovery is Phase 2a-driven; aux added complexity without
  measurable contribution

Adding forgiveness_trace would risk:
- Another decorative mechanism that "looks like memory" but doesn't
  affect action space
- Conceptual bloat without empirical motivation
- Creating another phantom for future Iter to retract

**Per project file §6 (forbidden)**:
- "추가 변수 마구 늘리지 않기"
- "임시 도구를 그대로 다음 단계 핵심으로 굳히지 않기"

The right move: keep current 8 layers, verify they produce predictable
dynamics (Iter 119 confirmed yes), advance to next priorities.

## 6. What COULD legitimately motivate adding a layer

A new memory layer should be added if:
1. Empirical observation reveals a dynamic that current layers can't
   explain
2. Project direction explicitly requires it (per Lee's request)
3. Story-level narrative requires it (e.g., "world remembers X
   across scenarios")

None of these currently apply. Iter 119 model fits observed dynamics;
project direction §6 forbids variable bloat; story-level narrative
hasn't surfaced unexplained gaps.

## 8. What could still be wrong (H4)

- Score-3 = 3 estimate based on count of layers + their interactions.
  Lee's intent for "memory channel 동시에 작동" might be stricter
  (e.g., requires crossover effects, not just simultaneous existence).
- "8 layers" double-counts: alignment_strength and density are
  state, not memory; rumor decay is mechanism, not state. Stricter
  count: 4-5 memory layers.
- Iter 119 confirmation tested predictive model for recovery rate
  but didn't separately probe each memory layer's contribution.
  Some layers might be redundant or unused.
- Adding forgiveness_trace etc. might genuinely improve dynamics;
  H2 ("not tried") applies. Could be worth a probe before deciding
  no-op is right.
- The "no aux-style phantoms" caution is itself an inference; new
  layers might genuinely contribute if empirically motivated.
